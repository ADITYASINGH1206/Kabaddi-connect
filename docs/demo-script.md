|---|---|

| 2:25 to 2:50 | Architecture slide: AWS Bedrock, Lambda, DynamoDB, S3, Location Service, Amplify, SAM. |
| 2:50 to 3:00 | Future vision: WhatsApp interface, voice in Hindi, municipal partnerships. |
